# Miró Missotten — portfolio

Single-page portfolio site: lamps, videos, music, food and other stubborn projects. Brussels.

## Structure

- `index.html` — the entire site (Tailwind via CDN, no build step)
- `assets/` — project images and the ringmaking video
- `check.py` — sanity check for broken links, anchors and tag balance (`python check.py`)

Live on GitHub Pages.
