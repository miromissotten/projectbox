# Carousel Bug Fixes

## Bug 1: Filter buttons do not work

**File:** `index.html` (~line 1854 in the `<script>` block)

**Root cause:** `carousel.querySelectorAll(".carousel-filter-btn")` searches within `.carousel-viewport` (`#project-carousel`), but the filter buttons are inside `.carousel-controls` — a sibling element, not a descendant. The query returns an empty NodeList, so no event listeners attach.

**Fix:** Change:
```js
var filterButtons = carousel.querySelectorAll(".carousel-filter-btn");
```
To:
```js
var filterButtons = document.querySelectorAll(".carousel-filter-btn");
```

## Bug 2: Cards are not angled, just horizontally squished

**File:** `index.html` (~line 169 in `<style>` block, `.carousel-viewport` rule)

**Root cause:** The `.carousel-viewport` CSS has no `perspective` property. The `paintCoverflow()` JS function applies `rotateY()` transforms to cards, but without `perspective` on the parent container, the 3D rotation is not visible — it renders as a flat horizontal compression.

**Fix:** Add `perspective: 1200px;` to `.carousel-viewport`:
```css
.carousel-viewport {
    /* existing properties ... */
    user-select: none;
    perspective: 1200px;
}
```

2. Click filter buttons (All, DEV, CRAFT, VIDEO, FOOD, and status filters) — cards should filter
3. Scroll the carousel — center card should appear angled (3D rotateY), side cards should be smaller and rotated away
